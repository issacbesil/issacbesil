### What I've built

**Toqan**: an AI analytics agent on BigQuery. Skip's re-engagement team used to file 90+ tickets a year just to get basic customer data. Now they just ask Toqan. Built the whole thing: the agent, the adoption KPIs, the rollout, and the measurement framework to track whether it was actually working.

**Reengagement Universe**: split Skip's full customer base into 4 behavioural cohorts by churn risk and engagement depth, then built targeted re-engagement strategies for each one. Holdout groups measured what actually brought customers back.

**CRM Lifecycle Measurement**: designed holdout testing and campaign lift frameworks for Skip's lifecycle programs. Every experiment result tied back to real retention and reactivation numbers.
